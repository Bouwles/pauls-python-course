title: Python does sums
concept: arithmetic
code: |
  print(240 * 3)
  print(720 / 100)
  print(6 / 2)
---
Python can do sums. Write numbers without quotes, and Python treats them as numbers, not text.

`+` adds and `-` takes away. `*` multiplies, because a keyboard has no × key. `/` divides.

`print(240 * 3)` works the sum out first, then prints the answer:

```text
720
```

Dividing with `/` always gives a number with a decimal point, even when it divides exactly. So `720 / 100` is `7.2`, and `6 / 2` is `3.0`.

That `3.0` surprises people. It's still three. `/` just always answers with a decimal point.
