Mira's pigeonholes are numbered from 0. The first hole is hole 0, so hole 3 is the fourth one along.

Find hole 3. Go by the numbers on the holes, not by counting from one.

Python numbers the items in a list the same way. The number is called an **index**, and it says how many steps along from the start an item is. The first item is no steps along: index 0.
