# The interface kit (REDESIGN.md 3.3, 3.6, 1.3, 1.4): pixel frames, icons, the heart and the brand.
#
# Frames are 24x24 9-slices with 8 px corners, applied with CSS border-image at 2x
# (border-image-slice: 8 fill; border-width: 16px). The middle third of every edge is
# the same pixel all the way along, so stretch and round both work. Pixels outside the
# stepped corners are transparent.
#
# Icons are 12x12 and drawn in chalk (M) only: the page recolours M to currentColor.
# The heart, the duck, the tack and the mark keep their own colours (the mark uses no M).

# --- Frames ------------------------------------------------------------------
